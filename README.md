# 暗記カード

スマホのホーム画面に追加して使う暗記アプリです（Wi-Fiなしでも動きます）。

- 問題データはここには置いていません。アプリの「問題データ」→「ファイルを選ぶ」で、手元のデータファイルを取り込みます。
- 新しい版にするときは、index.html・sw.js などを置き換えます（sw.js の VERSION も上げる）。

## 漢字カード（kanji/）

漢字だけの別アプリです。https://katsuyaamano-bit.github.io/anki-card/kanji/ を開いてホーム画面に追加します（暗記カードとは別のアイコンになります）。

- 今日の30問（復習の語が先、残りは新しい語）。指で書く欄 → 答え → 書けた／書けなかった。書けなかった語は4問あとにもう一度出ます。
- 問題データはここには置いていません。アプリの「ファイルを選ぶ」で、手元のデータファイル（kanjicard-data 形式の .json）を取り込みます。
- 新しい版にするときは kanji/sw.js の VERSION を上げます。
- 暗記カード（ルート）と漢字カード（kanji/）の sw.js は、自分の保存分（ankicard- / kanjicard-）だけを消すようにしてあります。
